# Engineering Mechanics I (CEng2021): Course Website

Course website for Engineering Mechanics I (Statics), Year II / Semester I, Academic Year 2026/2027, Department of Civil Engineering. Built with [VitePress](https://vitepress.dev) with LaTeX math via `markdown-it-mathjax3`.

## Local development

Requires Node.js 20+.

```bash
npm install        # first time only; commit the generated package-lock.json
npm run docs:dev   # dev server with hot reload
npm run docs:build # production build -> docs/.vitepress/dist
npm run docs:preview
```

The site is served under the base path `/statics-course/`, so the local URL is `http://localhost:5173/statics-course/`.

## Deployment (GitHub Pages)

1. Name the repository `statics-course` (or change `base` in `docs/.vitepress/config.js`).
2. Commit `package-lock.json` (the workflow uses `npm ci`).
3. In the repository go to **Settings → Pages → Source** and choose **GitHub Actions**.
4. Push to `main`. The workflow in `.github/workflows/deploy.yml` builds and deploys the site.

## Diagrams

All figures in the chapter pages are SVG files in `docs/chapters/img/`. They are generated by small Python scripts in `tools/diagrams/` (`ch1.py` to `ch7.py`, with the helper library `figlib.py`), so any figure can be edited and regenerated:

```bash
cd tools/diagrams
python3 ch1.py   # regenerates the Chapter 1 figures (no extra packages needed)
```

`scenes.py` draws the seven realistic site illustrations (one per chapter). `preview.py` is an optional contact-sheet helper that needs `pip install cairosvg pillow`.

## Worked solutions

Full step-by-step solutions for the tutorial problems are in `docs/solutions/`. To hide them until you want to release them, set `solutionsPublished = false` at the top of `docs/.vitepress/config.js` and rebuild.

## Student features

- **Quick Quiz** at the end of each chapter: edit questions in `docs/.vitepress/theme/quizzes.js`.
- **Click a figure** to zoom it (useful on phones). Chapters and the Formula Sheet have print styles.
- **Last updated** dates appear on each page when the site is built from a git repository.
- A pull-request workflow (`.github/workflows/check.yml`) builds the site and fails on dead links.

## Content rules

- Do not copy Meriam/Kraige problem statements or diagrams. Write original problems or cite the textbook section.
- Do not publish instructor phone numbers.
- Tutorial answers go in `<details><summary>Show answer</summary> ... </details>` blocks.
- Chapter pages follow a fixed order: title, metadata line, Textbook Mapping, Learning Objectives, Key Concepts, Worked Examples, Tutorial Problems, Self-Check.
