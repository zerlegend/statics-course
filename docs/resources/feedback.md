# Feedback

Your feedback improves the course. Please tell us about:

- **Errors** on this site: a wrong number, a broken formula, a figure that does not match the text, or a typo.
- **Unclear explanations** you would like improved.
- **Suggestions** for extra examples or topics.

## How to send feedback

- **Email:** [zerlegend@gmail.com](mailto:zerlegend@gmail.com). Please include the page name, the section and what you think is wrong.
- **Telegram channel:** use the course channel (link shared in class).

When reporting an error, mention the page address (for example, `/chapters/ch4-structures`) and, if possible, a screenshot.
