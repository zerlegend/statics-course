# Course Learning Outcomes (CLOs)

The CLOs follow the official course outline. Each one is mapped to a **Bloom's taxonomy level** and to the **ABET Student Outcomes** (Criterion 3, engineering programs), so the course can also be reported against international accreditation frameworks.

## Indicative performance criteria

A student has met a CLO when their solution shows:

1. a clear sketch or free-body diagram with all forces, reactions, dimensions and axes;
2. the correct principle and equations, with assumptions stated;
3. correct algebra and arithmetic with consistent SI units;
4. a reasonableness check (for example, a second equilibrium equation, or the expected sign and size of the answer); and
5. a short conclusion that interprets the result for the physical situation.
